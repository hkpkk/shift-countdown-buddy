# 🐈‍⬛🐈 Shift Countdown Buddy

Đồng hồ đếm ngược giờ nghỉ trưa (`12:00`) và giờ tan ca (`17:00`) siêu nhẹ (`0.0% CPU`), mang phong cách **Classic Serif (*Baskerville & Garamond*)** kết hợp tông màu **Vintage Rose** và cặp đôi **Mèo Cam béo & Mèo Đen điềm đạm**.

---

## ✨ Tính năng chính
- **Gọn nhẹ tuyệt đối (`0.0% CPU`)**: Chỉ cập nhật đúng 1 nhịp mỗi giây, không hao pin hay làm nóng máy.
- **2 phiên bản tiện lợi**:
  - **[`ShiftBuddy.html`](ShiftBuddy.html)** *(Zero-install Web App)*: Mở trực tiếp trên Chrome/Edge, bấm nút **`📌`** để tách thành cửa sổ nổi luôn nằm trên góc màn hình (*Document Picture-in-Picture*), nút **`▴`** để thu gọn.
  - **[`src/ShiftBuddy.cs`](src/ShiftBuddy.cs)** *(Native Windows `.exe` ~18 KB)*: Chạy [`build_exe.bat`](build_exe.bat) để biên dịch thành file `ShiftBuddy.exe` độc lập trên Windows mà không cần cài thêm bất kỳ thư viện nào.
- **Góc tương tác xả stress**: Chạm vào đôi **Mèo Cam & Mèo Đen** để xoa đầu và nhận các lời nhắc thư giãn mắt, uống nước, giữ dáng ngồi.

---

## 🚀 Cách dùng nhanh
1. **Dùng ngay trên trình duyệt**: Tải file **`ShiftBuddy.html`** về máy ➔ Mở bằng Chrome hoặc Edge ➔ Bấm **`📌`**.
2. **Biên dịch bản `.exe` trên Windows**: Nháy đúp vào **`build_exe.bat`** để tạo và mở `ShiftBuddy.exe`.
